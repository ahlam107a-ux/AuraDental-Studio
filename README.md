# 🦷 AuraDental Studio — Modern Dental Clinic Web Application

![AuraDental Studio Preview](Bright%20smile%20doctor.jpg)

AuraDental Studio is a modern, responsive, and highly interactive web application designed for a luxury aesthetic dental clinic. It provides patients with a seamless experience to explore dental procedures, preview whitening results interactively, book appointments through a step-by-step wizard, and authenticate.

---

## ✨ Key Features

* **Interactive Glassmorphism Navigation:** Responsive header featuring quick jump links and real-time patient session status.
* **Teeth Whitening Shade Simulator:** An interactive tool allowing patients to adjust and preview enamel shade transformations before booking.
* **Before & After Comparison Slider:** Custom drag/swipe slider showcasing real cosmetic smile transformations.
* **Interactive Clinic Virtual Tour:** Seamless image gallery tab system to explore reception lounges and treatment suites.
* **Doctor Selection & Booking Wizard:** A multi-step appointment wizard allowing patients to select specific specialists, services, dates, and time slots.
* **Patient Authentication System:** Built-in Sign In and Registration modal interface with active session badges.
* **Fully Responsive & Accessible:** Designed with a modern UI palette, smooth scroll animations, and fluid mobile/desktop views.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic structure and web components.
* **Tailwind CSS** — Utility-first styling, glassmorphism, responsive grids, and UI animations.
* **JavaScript (ES6+)** — Interactive DOM manipulation, custom state management for modals, shade simulator, and booking wizard.
* **FontAwesome 6** — Modern icon set for UI micro-interactions.
